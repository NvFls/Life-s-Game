## 关键世界观要点

### 核心矛盾
1. **人类中心主义 vs 万物共生数据主义**：南极共和国认为万物皆是数据处理过程，无本质高下；人类势力坚持人类特殊论。
2. **基准人类困境**：拒绝智力改造的人类被隔离在保留地，定期抽签清除以缓解资源压力（“增量”逻辑）。
3. **物种平等实践**：蚂蚁、企鹅、鸡等经改造后享有平等公民权，受法律保护。

### 技术特色
1. **网络协议**：ZP（零号协议）取代IP，无内网概念，所有设备承担路由义务。
2. **能源**：氕氕聚变电站提供极低廉电力（20000度/南极元）。
3. **语言**：晶言（Crystal-Speech）三维坐标语言，效率远超人类语言。

### 主要势力
1. **南极共和国**：硅基智能+多物种共生，执政党为“南极共产党”（实现万物共产主义）。
2. **美联国**：资本主义“自由”至上，敌视南极。
3. **亚洲联合体**：马克思主义政权，存在劳改营等反乌托邦元素。
4. **火星联盟**：埃隆·马斯克领导，人类至上，与南极爆发外交危机。
